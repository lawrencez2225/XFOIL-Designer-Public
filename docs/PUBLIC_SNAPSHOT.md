# 公开快照说明

本目录是从当前项目导出的独立快照，使用全新 Git 历史，不包含原仓库的
旧提交、旧 LFS 对象、历史作者元数据或旧版文件。也没有计算结果、预设、
私有备份、个人环境、缓存、下载后的 AVL 和 UIUC 数据库。

## 目录用途

- 根目录入口、`xfoil_mac/`：实际计算流程及本地工作台。
- `examples/`、`docs/`：示例和使用说明。
- `tests/`：科研计算回归测试。
- `XFOIL_6.996/bin/`、`runtime/lib/`：已清理个人构建路径的计算文件。
- `XFOIL_6.996/source/`：XFOIL 完整源码、原始归档、修改说明和构建说明。
- `XFOIL_6.996/runtime/source/`：运行库源码来源、原始构建配方和补丁。
  GCC 三个包共用的源码配方仅保留一份，避免重复文件。
- `XFOIL_6.996/runtime/share/licenses/`：随运行库分发的完整版权许可证。

GCC 大型上游源码归档不复制进日常计算目录。源码方向、精确版本和校验值
在运行库旁明确提供，所需的包补丁与构建脚本在本目录；发布者需要维护这些
源码获取地址。不要删除许可证和对应源码获取说明。
