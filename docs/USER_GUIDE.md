# 使用说明

## 1. 开始与保存

双击项目根目录的 `启动工作台.command`。首页选择功能，填参数，点击“检查设置”，查看算例数，然后“开始计算”。任务顺序执行，可以在“任务进度”取消；已完成数据保留。

每次计算都能修改弦长、密度、黏度、声速。输入速度时自动算 Re 与 Mach；输入 Re 或 Mach 时可以只给一个，由尺寸与环境推算另一个。两者都给时保持独立给定值。工作台保留上次设置，还可以给设置命名并保存预设。TYPE 2/3 只用于攻角扫描；CL 直接求解、型阻修正与设计按固定 Re/Mach 处理。

## 2. 翼型 / Re / Mach 扫描

输入一个或多个 NACA 编号，或搜索坐标数据库、导入 `.dat/.txt`。指定攻角起点、终点、步长；多个 NACA、Re、Mach 会组成笛卡尔组合。实际速度模式对应单一物理工况。

结果首页按算例列出链接。算例内包含 CL、CD、CM、升阻比、Cp 和压力矢量。交互查看器可以切换翼型与攻角；失败点会断线，攻角曲线上以红叉标出，诊断表保留重试次数、种子攻角与日志。自动加密可增加重要区间采样，但不保证所有点收敛。

启用额外重试后，程序先从邻近的收敛攻角逐步逼近；仍失败时，再尝试重新初始化边界层（XFOIL `INIT`）。恢复过程保持 Re、Mach、面板和转捩设置不变，也不放宽收敛要求。所有尝试共用该算例的时间上限，失败记录和采用的恢复方式会保留在诊断中。关闭额外重试时，新计算不会自动增加恢复尝试。

`data/…/attempts/` 保存每次输入命令和求解器原始输出。`run.json` 是配置和进度清单，不是需要手写的输入文件。

## 3. 按 CL 直接计算

选择“按目标升力 CL 直接计算”，输入 `0.2 0.5 0.8` 等目标。程序直接使用 XFOIL 的 CL 命令反求攻角，而不是从已有曲线上读取数值。实际 CL 必须在目标 ±0.00015 内，且有收敛极曲线与 Cp 才记为成功；请求边界层时还必须有与面元几何一致的有效表面数据。失败点不参与图表中的有效结果。

每个目标都有 Cp、边界层和原始尝试记录。此模式的清单为 `lift_run.json`。它与攻角扫描的数据类型不同，原来的攻角结果对比入口不会把两种清单混在一起。

## 4. 转捩、面板与边界层

- **Ncrit**：eⁿ 自然转捩模型的临界放大因子。它不是一个可以简单换算成表面粗糙度的旋钮。
- **上 / 下表面强制转捩 x/c**：例如 0.3 表示最迟在 30% 弦长处强制转捩；自然转捩可能更早。默认 1 不在更前方强制转捩。
- **面板数**：本接口支持 40–500，默认 240。数值更大不自动代表结果更好。
- **聚集系数、后缘 / 前缘密度比**：控制面板分布。比较不同工况时应记录并保持一致。

勾选“保存边界层”后，每个已收敛点都保存 Cf、位移厚度 Dstar、动量厚度 Theta、形状因子 H。图中用点线标出转捩位置；上、下表面分别绘制。CSV 另保留尾迹行，并明确标记 `wake`，不把尾迹当翼面。

Cf、H、Ue/Vinf 为无量纲量；保留的 H 字段对应 XFOIL DUMP 的运动学形状因子 HK。Dstar、Theta、s、x、y 使用输入坐标长度单位；单位弦长输入下厚度数值就是相对弦长。数据损坏、表面记录不完整或与几何不匹配时明确报告失败，既不跳过后继续分类，也不把空文件判为成功。

负 Cf 是边界层解中的反向壁面剪切信息；单凭它或求解失败都不能确定真实三维失速。

## 5. 面板敏感性与双向逼近

“面板敏感性检查”填写如 `120 240 360`。其他设置相同，逐一真实计算；差值相对于最高面板数，仅比较双方收敛的相同攻角。报告不把最后两个数相近直接当成已证明网格无关。

“双向逼近检查”选择已有攻角扫描，填关键攻角。留空时优先检查失败点；没有失败点则检查采样中的最佳升阻比点。分别从目标上下 1° 逼近，保留双方原始解。默认一致性阈值为 |ΔCL|≤0.002、|ΔCD|≤0.0002。双向差异不会被平均掉，也不会覆盖原结果。

## 6. 实测基准与自己的实验

内置基准使用 Ladson / NASA TM 4074 的 NACA 0012 公开测量值，Re=600 万、Mach=0.15。80、120、180 grit 三个系列分别使用，不能拼成一组。默认只比较 |α|≤10.2°，可调整到不超过 15°。

来源文件只注明粗糙带系列，未给出转捩位置；界面里的 Xtr=0.05 是明确披露的近似假设。程序使用原始有限后缘厚度 NACA 0012，未采用 TMR 为 CFD 网格修改过的尖后缘几何，也不解析砂粒粗糙度阻力。输出记录原始数据 SHA-256、来源、所有假设和逐点误差；不会用预设误差阈值宣称验证通过。

自己的实验仍使用菜单 10 或 `--experiment`。CSV 列为 `alpha,CL,CD,Re,Mach`，可加 `CM,airfoil`。只有工况匹配且唯一可插值的区间才参与比较；不跨失败点或向范围外推断。

## 7. AVL 机翼

工作台直接输入全翼展、根尖弦长、前缘后掠、上反角、根尖安装角和 NACA 编号。点击“更新三维预览”，拖动旋转、滚轮缩放，在截面菜单查看根部或翼尖。可载入已有 JSON，或从历史“载入设置”，使用截面编辑器修改多翼面模型的各截面；菜单 12 也提供纯文字的创建 / 编辑向导，并支持坐标文件翼型。

所有长度使用同一模型单位。新建模型的参考面积、平均气动弦和翼展按主翼自动计算。载入已有模型、修改截面和更新预览均保留显式参考参数；需要更新时点击“重算参考尺寸”，默认仍保留力矩参考点，只有明确勾选才将该点重置。镜像模型的翼展取左右翼尖全距离，面积只累计实际建模翼段，不补造翼根中央空缺区域；安装角 i=0° 是局部弦线基准，i=-1° 是该截面相对基准降低 1°。根部 0°、尖部 -1° 表示 1° 几何洗出。外观预览会旋转截面来展示扭转；AVL 求解器的截面安装角通过流动边界条件实现，不旋转薄面输入坐标。

默认模型本来就是矩形平面形状：全翼展 8、根尖弦长都为 1。看到矩形俯视图是正确的；翼型厚度在三维图和截面中体现。改变尖弦长、后掠后俯视轮廓才变为其他形状。

支持攻角和目标 CL 两种机翼工况。结果有三维外形、俯视轮廓、展向载荷、诱导阻力及稳定导数。AVL 是附着流涡格模型，不计算黏性分离或真实失速；只有导数也不能证明整架飞机的动态稳定性。

首次没有 AVL 时，菜单 13 安装官方 Apple Silicon 版本；本机已安装后无需重复操作。

## 8. 机翼黏性阻力估算

选择已有 AVL 计算，输入速度、环境和“模型 1 单位等于多少米”。速度推导的 Mach 必须与 AVL 算例一致。比如 AVL M=0.1、声速 340.3 m/s 时，速度应为 34.03 m/s。

对每条 AVL 条带，以当地弦长计算 Re，按截面插值得到当地翼型，再从对应 XFOIL 极曲线在局部 cl 上取型阻。以条带面积积分得到机翼型阻：`CD_profile = Σ(cd × strip_area) / Sref`。报告的总 CD 为该型阻加 AVL 的诱导 CD；原 AVL 的固定型阻 / CDvis 不会再加一次。

AVL 条带须通过表面、编号、条带数及面积完整性校验，原始输出被改动或损坏时保留失败原因，不据剩余条带宣称完整。全部或末尾工况失败也会进入报告。缺少收敛支撑、跨断点、多重 CL 交点时不外推；只要某条带缺失，总 CD 留空并报告覆盖率。当前实现限制前缘后掠 ≤20°、上反角 ≤15°、零侧滑、单调展向截面；不含交叉流、机身阻力、干扰阻力和黏性载荷反馈。适用于初步附着流估算。

## 9. 翼型设计与多工况搜索

给出厚度倍率、弯度倍率、襟翼偏角的候选列表，也可以指定第二个 NACA 和混合比例。例：厚度 `1`、弯度 `0.8 1 1.2`、襟翼 `0 3`，产生 6 个候选。每个列表只填一个值时就是单次形状修改并评估。坐标归一化前后的转换记录在几何检查中。

指定每个候选都要满足的 Re、Mach、目标 CL，并设置最小厚度和最大 |CM|。程序在所有工况真实求解，比较平均 CD（越小越好）及最差 CL/CD（越大越好），输出可行候选的 Pareto 集合。失败候选与违反约束的候选也保留。

范围限制：厚度倍率 0.5–1.8、弯度倍率 0–2、襟翼 ±15°、铰链 x/c=0.5–0.95、混合比例 0–1。最多 60 候选、8 工况、160 次求解。形状基础 NACA 支持四位编号；普通 XFOIL 扫描仍支持四位 / 五位。搜索结果不是全局最优保证，也不包含螺旋桨或电机匹配。

## 10. 历史、继续与文件

“计算历史”中可以打开报告、载入设置、复制重跑、继续新版任务，以及把整份报告打包为 ZIP。新版报告用相对链接，解压后打开 `report.html`，图表和原始记录一起保留。

继续计算只补缺失点；输入坐标、设置、求解器或计算代码改变时会拒绝混合旧结果。此时“复制重跑”会新建目录，旧结果不动。旧版原始算例可继续使用原参数的 CLI `--resume`；工作台建议复制设置后重跑。已经完成的算例直接复用并刷新图表。

新版每次任务的目录约定：

```text
projects/时间_功能/
  report.html       ← 先打开这个
  job.json          ← 本次设置、状态
  data/             ← 详细算例、图表、原始日志
  inputs/           ← 某些功能的输入模型
  task.log          ← 工作台运行信息
  report.zip        ← 点击打包后才生成
```

原有 `study_…`、`single_calculations/`、`wing_…` 正式数据保留原路径。过时的开发验证输出已删除，新测试使用系统临时目录。不要手动拆分单次计算内部的文件；用报告入口查看即可。

## 11. 原有菜单与高级命令

| 菜单 | 功能 |
|---|---|
| 1 / 2 | 单翼型 / 坐标文件夹批量计算 |
| 3 / 4 | 原生交互 XFOIL / 退出 |
| 5 / 6 | 已有结果对比 / 多 NACA 与 Re、Mach 扫描 |
| 7 / 8 | 按条件筛选翼型 / 性能地图 |
| 9 / 10 | 坐标检查和归一化 / 实验 CSV 比较 |
| 11 | 离线交互 Cp、极曲线查看器 |
| 12 / 13 | 机翼向导 / 安装官方 Apple Silicon AVL |
| 14 / 15 | 本地工作台 / 历史列表 |

命令行示例（在项目根目录、`xfoil-work` 环境内）：

```sh
python -m xfoil_mac --polar --naca 2412 --speed 20 --chord .3 --aseq -4 12 1 --ncrit 9 --panels 240 --boundary-layer --headless --outdir xfoil_runs/my_run
python -m xfoil_mac --lift --naca 2412 --re 1000000 --mach .05 --cseq .2 .8 .2 --outdir xfoil_runs/my_cl
python -m xfoil_mac --panel-study 120 240 360 --naca 0012 --re 1000000 --mach .05 --aseq 0 8 2
python -m xfoil_mac --check-directions xfoil_runs/my_run --check-angles 4.25 8
python -m xfoil_mac --benchmark
python -m xfoil_mac --design examples/design.json
python -m xfoil_mac --wing-wizard
python -m xfoil_mac --couple-wing xfoil_runs/my_wing --speed 34.03
python -m xfoil_mac --history
```

`--target-cl` 仍表示从攻角扫描中提取目标 CL 的性能；直接求解使用 `--lift --cl-values` 或 `--lift --cseq`。CL 为无量纲量，序列步长不受攻角 0.001° 网格限制；两种输入均最多 200 个目标、范围 −5 到 5。`--study-config` 可运行工作台格式的配置文件；`--help` 列出完整参数。
